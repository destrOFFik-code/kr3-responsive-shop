# ShopProject — контрольная работа №3

«Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

Автор — Пчелкин А. С., группа ЭФБО-11-25.

Учебный магазин товаров и услуг для рабочего места на основе проекта КР №1.
Форма заявки выполняет проверку в браузере. Данные заявки остаются локальными.

## Запуск

Откройте `index.html` или запустите сервер из этой папки.

```bash
python3 -m http.server 8000
```

Откройте [магазин](http://localhost:8000/).

## Практическая работа №12

- `viewport` и `css/responsive.css` подключены на всех семи страницах.
- Базовые стили рассчитаны на телефон. Медиазапросы с `min-width` добавляют колонки на 768, 1024 и 1200 px. На широких экранах шапка и фильтр закрепляются при достаточной высоте окна.
- В главном блоке размер заголовка меняется через `clamp()`. Действия располагаются вертикально на телефоне и в ряд на широком экране.
- Каталог перестраивается из одной колонки карточек в две и затем три. Фильтр переносится из верхнего блока в боковой.
- Для фотографий указаны `srcset`, `sizes`, размеры в разметке и варианты на 400, 800 и 1280 px. Первая карточка главной предлагает WebP через `picture` и JPG в качестве резервного формата. Фотографии ниже первого экрана используют отложенную загрузку.
- Поля заявки размещаются в одну колонку на телефоне и в две с 768 px. Таблицы прокручиваются внутри своих контейнеров. Модальное окно ограничено размером окна браузера, а кнопка «Наверх» перемещается в подвал на узком экране.

### Проверка

Все семь страниц проверены в Chromium через DevTools Protocol на ширинах **360, 430, 768, 1024 и 1440 px**. На каждой ширине проверены отсутствие горизонтальной прокрутки страницы, число колонок карточек и формы, размер и закрытие окна, выбор товара из URL и валидация заявки. Браузер выбрал `lamp-400.webp` на всех пяти ширинах при плотности 1×, поскольку карточки занимали меньше 400 CSS px. На 360 и 430 px прокрутка находилась внутри контейнера таблицы.

Ветка работы — `feature/responsive-layout`.
